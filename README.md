## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

### Prerequisites
* Node.js (v18 or higher recommended)
* npm, yarn, or pnpm

### Installation

1. Clone the repository
   ```sh
   git clone https://github.com/your-username/ip-solutions-frontend.git
   ```
2. Navigate into the directory
   ```sh
   cd demo_ish
   ```
3. Install dependencies
   ```sh
   npm install
   ```
4. Setup Environment Variables
   Copy `.env.example` to `.env` and fill in your MongoDB URI and Resend API keys.
   ```sh
   cp .env.example .env.local
   ```
5. Run the Development Server
   ```sh
   npm run dev
   ```
6. Open your browser and navigate to `http://localhost:3000` to see the magic happen!
